# Security policy

## Reporting a vulnerability

Please do not report security problems in public issues. Use GitHub's private reporting instead: open the repository's **Security** tab and choose **Report a vulnerability**.

Include what you found, how to reproduce it, and what an attacker could do with it. You should get a reply within a week.

## Supported versions

Security fixes go into the latest release.

## Scope

Examples of what counts: a page or sitemap that makes politescrape use unbounded memory or time, read local files, or send requests a user did not ask for; and robots.txt handling that fetches addresses the rules forbid.
